# Quiz-App

Quiz App is a simple and interactive web application that allows users to answer multiple-choice questions and test their knowledge.

Key Features
User-friendly and responsive interface.
Multiple-choice quiz questions.
Displays one question at a time.
Users can select an answer and move to the next question.
Automatically calculates the final score.
Displays the user's score after completing the quiz.
Provides instant feedback for correct and incorrect answers.
Option to restart the quiz and try again.
Technologies Used
HTML – Creates the structure of the application.
CSS – Provides styling and responsive design.
JavaScript – Handles questions, answer validation, score calculation, and user interactions.
Project Objective
The main objective of the Quiz App is to build an interactive frontend application while practicing HTML, CSS, JavaScript, Git/GitHub, and Jenkins CI/CD.
